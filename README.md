# Examinerande gruppuppgift - E-handel
Detta projektet innehåller analys av data från ett e-handelsföretag för att hitta och se mönster i försäljningen, för att ge ledningen ett underlag för att bestämma utformningen av kommande kampanjperiod.


## Python-version
Projektet använder Python 3.14.3
För att kunna köra projektet behöver du rätt version.

Kör projektet med hjälp av:

pip install -r requirements.txt

## Roller

CHRISTIAN:
src/io_utils.py = utility-funktioner

JULIA:
metrics.py = nyckeltals-funktioner

OLIVER:
viz.py = plot-funktioner

ULRIKA:
